# FeezBuzz Java

FeezBuzz est une implémentation simple en Java de l'exercice classique FizzBuzz.

Ce projet inclut également des tests unitaires écrits avec **JUnit**, pour garantir le bon fonctionnement de la logique.

## 🔍 Description

La règle est la suivante :

- Si le nombre est divisible par **3**, renvoyer `"Fizz"`
- Si le nombre est divisible par **5**, renvoyer `"Buzz"`
- Si le nombre est divisible par **3 et 5**, renvoyer `"FizzBuzz"`
- Sinon, renvoyer le **nombre lui-même** sous forme de chaîne de caractères

## 🛠️ Technologies utilisées

- Java 8+
- JUnit 4
